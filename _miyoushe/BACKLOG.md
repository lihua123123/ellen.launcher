## ⚠️ 本轮**故意不做**的事

### 1. 名字解析迁移到管线（**这是「修 7 个错误合并」的真实前置**）

**原估计 1~2 小时，实测不是。** 2026-09-30 试跑 `finalize` 的结果（已回退）：

| 改动面 | 数量 |
|---|---|
| 新增条目 | 6（`深海龙蜥·吞雷`/`·啮冰` 是预期的，另有 `丘丘雷兜冠` 等非预期） |
| **消失条目** | **5**（`深黯钓客`、`窟岩·大灵显化身`、`贪食匿叶龙山王` …） |
| `resistances` 值变化 | 7（`风蚀沙虫`、`无相之火`、`翠翎恐蕈` …） |
| `gap_override` | **exit 1**，evidence **99 → 94** 行 |

**根本原因**：换名字解析器会改变每张卡的 `meta`，而
`gap_override.py` / `derive_evidence.py` / `label_map.py` 都按**老键**（`(take,label)`）找行
→ 5 行采纳值**没被注入** → 那几行带的是**本地未验证值**。
**所以「修 7 个错误合并」= 一次管线迁移，不是改一行。**

已加的护栏：`finalize.py` 现在在 `gap_override` 非零退出时**中止**（原先只 print 就继续跑
→ 会**静默产出**带本地未验证值的档案）。

**受影响的具体错误合并**（按能否被现工具修好分）：
- ✅ 现工具已能修：`深海龙蜥·原种`（04/010→吞雷、04/011→啮冰）、`风蚀沙虫`（04/027→None）、
  `重拳出击鸭`（14/020→None）
- ❌ 仍需产品决策：`爆炎树`（04/003 焚天爆炎树）、`古岩龙蜥`（04/008 ·溟冬）、
  `魔像督军`（04/030 ·协律师）、`兆载永劫龙兽`（06/018 重武装…）
  —— 这 4 张的**变体全名不在元数据里**，属于下面的「变体」条目

**下次入口**：先把 `gap_override` / `label_map` / `derive_evidence` 改成**按 `(take, 行位)` 取行**
（不依赖解析出来的名字），跑一遍并**按条目名比对**，逐个解释 6 新/5 消/7 变。

### 3. `Monster.json` 覆盖度：**194/600 = 32.3% 的卡匹配不上任何元数据名**

**下次入口**：这是**新项目量级**（产品决策 + 元数据补充 + UI 改造），不是收尾附加题。

`狼追猎者 → None`，同时不能破坏 `lookup` 现有的「共后缀 + 幼前缀对齐」正确成果。
